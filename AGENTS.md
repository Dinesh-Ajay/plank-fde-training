# WorkBot - Project Instructions

## Project Overview
WorkBot is a production-oriented web application developed as part of a 40-day AI Forward Deployed Engineer course.

## Technology Stack
- Next.js
- TypeScript
- React
- Tailwind CSS
- GitHub
- Vercel

## Development Guidelines
1. Write clean, maintainable code.
2. Follow TypeScript best practices.
3. Create reusable components.
4. Follow secure coding practices.
5. Avoid unnecessary dependencies.
6. Write tests for important functionality.
7. Run lint and build checks before completing changes.
8. Never commit secrets or API keys.
9. Keep changes small and focused.
10. Explain important implementation decisions.

## Git Workflow
- Use feature branches.
- Never develop features directly on main.
- Keep pull requests small.
- Review changes before merging.
